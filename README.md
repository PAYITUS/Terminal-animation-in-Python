# Terminal-animation-in-Python
This is an ASCII animation player for the terminal, compatible with both cmd and bash

It works on Windows 11 and 10, but it might give you problems on Windows 7

On Linux, it works on all distributions; if it doesn't work, it's because you don't have `curl` installed. You can install it using your package manager—such as `apt` on Ubuntu, `pacman` on Arch, etc.
